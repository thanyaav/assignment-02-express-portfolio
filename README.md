## Project Description
This project is a personal portfolio website developed using Node.js, Express.js, and EJS templates.

The website introduces my background, education, technical skills, and academic projects.

## Technologies Used
- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Git and GitHub

## Website Pages
1. **Home:** Introduction and portfolio overview.
2. **About Me:** Personal background and introduction video.
3. **Projects:** Academic and technical projects.
4. **Contact Me:** Contact form.

## Project Structure
- `app.js` - Express application configuration
- `routes/index.js` - Website routes
- `views/` - EJS page templates
- `views/partials/` - Shared header, navbar, and footer
- `public/stylesheets/` - CSS files
- `public/images/` - Portfolio images
- `public/videos/` - Introduction video

## How to Run the Project
1. Install Node.js.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Install dependencies:

   npm install

5. Start the application:

   npm start

6. Open http://localhost:3000 in your browser.
